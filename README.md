# **NxtTrendz - E-commerce Web Application**

## **Project Overview & Features**

An e-commerce web application inspired by platforms like Amazon, flipkart etc. The project was built within a week, integrating both frontend and backend functionalities to provide a seamless shopping experience. The main features include:

- **Registration and Login** – Users can create accounts seamlessly and log in securely.
- **Product Listings** – Users can browse, search, filter, and sort products dynamically.
- **Cart System** – Users can add products to their cart, view and manage their orders.
- **Checkout System** – Users can proceed to checkout, edit and finalize their order details.
- **Responsive Design** – The application is optimized for various screen sizes, ensuring a consistent user experience across devices.
- **Optimized Caching** – The application caches API responses for up to an hour, reducing unnecessary network requests and optimizing data fetching.
- **Secured Authentication and Authorization** – The application implements a token-based flow ensuring user sessions are seamless and secure.
- **Frontend Validation and Backend Sanitization** – The application uses input validation in the frontend and request sanitization in the backend.
- **Performance Optimization** – The application is optimized for performance by caching frequently accessed data, lazy loading, and reducing unnecessary re-renders.
